APM Knowledge Library — visual direction options

Six ways to make the renamed panel more interesting to browse. Each box is a self-contained mockup of just the panel's drawer, using the game's existing palette (parchment cards, zinc chrome). Not wired to real data — just shapes and layout to react to.

Option 1

Bookshelf of spines

Modules render as book spines grouped by category. Tap a spine to "pull it out" and flip open to the summary below. Leans hardest into the "library" rename.
